# @deepseek-ai/dsh-client-ui-brand-official

English | [中文](README.zh.md)

## Summary

This package gives the Web client the iVeman mark in the sidebar and conversation hero, with DeepSeek Harness attribution in the sidebar name. It registers in every client build profile. It has no runtime state and does not affect model requests.

<a id="use-this-package"></a>
## Use this package

Mount this plugin in the browser roster to show the iVeman brand in the sidebar and conversation hero.

### Choosing the profile

The plugin registers its brand occupants regardless of `DSH_CLIENT_BUILD_PROFILE`. `DSH_CLIENT_TITLE` separately sets the browser title at build time.

### Replacing the brand

A deployment with another identity leaves this package out and composes a package that occupies the sidebar and hero brand slots. There is no brand configuration form here.

<a id="understand-the-implementation"></a>
## Understand the implementation

<details>
<summary>Implementation internals — click to expand</summary>

The sidebar mark and name register together after both slots are declared; the hero mark registers with its own slot. The name and attribution use this package's locale dictionary. Each registration withdraws when its declaring slot unloads. The browser half is [`src/client/index.ts`](src/client/index.ts); the node half is an empty Loader seat. The browser title is a build-environment concern (`DSH_CLIENT_TITLE`), outside the slot system.

</details>

## Model Experience

None, as the package contributes browser presentation only; nothing here reaches a model request.

#### KV Cache effect

None; this package neither assembles nor sends a provider request.

## Known Limitations and Deferred Work

<a id="known-limitations-and-deferred-work"></a>


These limits define how brand presentation is supplied. They are current package constraints, not a brand-design comparison or a task backlog.

- **One occupant set** — alternative presentation belongs in another Cordis package occupying the sidebar and hero slots.
- **The browser title is independent** — `DSH_CLIENT_TITLE` selects title text at build time rather than through a UI slot.
